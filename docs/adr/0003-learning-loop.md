# ADR-0003: 闭环学习系统

**状态**: 已接受
**创建日期**: 2026-05-02
**更新日期**: 2026-05-02

---

## 上下文

AI 编码助手应该：
- 从经验中学习
- 自动提取可复用模式
- 持续改进质量

当前系统缺乏：
- 自动学习机制
- 模式固化能力
- 知识积累系统

## 决策

实现闭环学习系统：

**学习触发**：
1. 会话结束时
2. Ralph 迭代完成后
3. 错误修复后
4. 用户确认后
5. 模式复用 3 次后

**学习流程**：
```
会话 → 提取模式 → 分类验证 → 生成Memory → 3次复用 → 生成Skill
```

**Memory 分类**：
```
memory/
├── errors/      # 错误模式
├── successes/   # 成功模式
├── feedback/    # 用户偏好
├── project/     # 项目特定
└── platform/    # 平台差异
```

## 理由

1. **持续改进**：系统越用越智能
2. **知识积累**：避免重复犯错
3. **用户驱动**：学习用户偏好
4. **质量保证**：验证机制确保质量

## 后果

**正面**：
- 系统自主进化
- 减少重复错误
- 适应用户习惯

**负面**：
- 需要存储管理
- 需要质量验证
- 可能积累低质量模式

## 替代方案

1. **手动维护** - 人工更新技能
   - 缺点：工作量大，易遗漏

2. **外部学习系统** - 独立的学习服务
   - 缺点：复杂，集成困难

3. **无学习** - 保持静态
   - 缺点：无法改进
