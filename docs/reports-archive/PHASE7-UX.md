### 3. 快捷键系统 ⌨️

**文件**: `scripts/dashboard/dashboard.js` (ShortcutManager)

**快捷键**:
```
全局快捷键:
  Ctrl+R     → repeat-last (重复上次命令)
  Ctrl+L     → clear-screen (清屏)
  Ctrl+H     → show-history (显示历史)
  Ctrl+D     → show-dashboard (显示仪表板)
  Ctrl+Q     → quick-actions (快速操作)
  Tab        → auto-complete (自动补全)

命令别名:
  /hbe:r      → /hbe-review
  /hbe:t      → /hbe-tdd
  /hbe:rf     → /hbe-refactor
  /hbe:sec    → /hbe-security
  /hbe:arch   → /hbe-architect
  /hbe-plan   → /hbe-plan
```

**使用方法**:
```bash
# 显示所有快捷键
node scripts/dashboard/dashboard.js shortcuts
```

### 4. 主题系统 🎨

**文件**: `themes/theme-manager.js`

**支持的主题**:
- **暗色主题** (默认) - 护眼，适合长时间使用
- **亮色主题** - 清爽，适合明亮环境
- **极简主题** - 纯文本，最高兼容性

**主题组件**:
```javascript
// 进度条
[████████████░░░░░] 60%

// 状态卡片
✅ 成功状态
⚠️  警告状态
❌ 错误状态

// 表格
┌──────────┬──────────┬──────────┐
│ 列 1     │ 列 2     │ 列 3     │
├──────────┼──────────┼──────────┤
│ 数据 1   │ 数据 2   │ 数据 3   │
└──────────┴──────────┴──────────┘
```

**使用方法**:
```bash
# 列出所有主题
node themes/theme-manager.js list

# 使用主题
node themes/theme-manager.js use light

# 预览主题
node themes/theme-manager.js preview

# 创建自定义主题
node themes/theme-manager.js create mytheme
```

## 集成到 HBE

### 配置文件

```json
// ~/.hbe/config.json
{
  "theme": "dark",
  "dashboard": {
    "enabled": true,
    "refreshInterval": 5000,
    "autoStart": false
  },
  "shortcuts": {
    "enabled": true,
    "custom": {
      "Ctrl+Shift+R": "repeat-last-review"
    }
  }
}
```

### Hook 集成

```json
{
  "hooks": {
    "post:session": [
      {
        "name": "show-dashboard",
        "command": "node scripts/dashboard/dashboard.js stats",
        "description": "显示会话统计"
      }
    ]
  }
}
```
