# Build-Error-Resolver Agent 使用教程

> **版本**: 3.2.0  
> **触发命令**: `/hbe-build-fix`  
> **用途**: 修复构建错误

---

## 快速开始

```
/hbe-build-fix
```

## 功能

- 🔧 诊断构建失败
- 💡 提供修复建议
- ✏️ 自动修复常见错误
- 📝 解释错误原因

## 支持的错误类型

- TypeScript类型错误
- ESLint错误
- 依赖冲突
- 配置问题
- 语法错误

## 使用示例

```
# 修复当前构建错误
/hbe-build-fix

# 修复特定错误
/hbe-build-fix TS2345
```
