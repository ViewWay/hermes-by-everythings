# 安全规则

## 密钥管理

### 禁止
- 硬编码 API Key、密码、Token
- 在日志中输出敏感信息
- 在 URL 中传递敏感参数
- 使用明文存储密码

### 必须
- 所有密钥使用环境变量
- 敏感配置使用加密存储
- 日志脱敏处理
- HTTPS 传输敏感数据

## 输入验证

### 所有用户输入必须
- 类型检查（数字、字符串、日期等）
- 长度限制
- 特殊字符过滤
- SQL/NoSQL 注入防护
- XSS 防护（输出编码）

### 文件上传必须
- 文件类型白名单
- 文件大小限制
- 文件名清理
- 病毒扫描（生产环境）

## 认证授权

- 所有 API 端点必须有认证检查
- RBAC 角色检查
- Token 过期和刷新机制
- 防暴力破解（限流）
- CSRF Token（表单提交）

## 依赖安全

```bash
# 定期检查
npm audit
cargo audit
```

- 及时修复 Critical/High 漏洞
- 锁定依赖版本（lockfile）
- 审查第三方包权限

## 加密

- 密码: bcrypt / argon2（禁止 MD5/SHA1）
- 传输: TLS 1.2+
- 存储: AES-256-GCM
- 随机数: crypto-safe RNG
