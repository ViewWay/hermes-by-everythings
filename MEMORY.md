# Hermes Memory Index

This directory stores persistent memory for the Hermes-by-Everything project.

## Error Patterns

- [Index System Migration Errors](memory/errors/index-system-migration-errors-20260502.md) — Three-layer index system migration and duplicate file cleanup
- [Internal References Path Errors](memory/errors/internal-references-path-errors-20260502.md) — Skills directory internal references using outdated paths

## Structure

```
memory/
├── errors/          # Bug fixes and error patterns
├── successes/       # Successful patterns to reuse
├── feedback/        # User feedback and preferences
└── platform/        # Platform-specific adaptations
```

## Memory Types

- **errors**: Bug fixes and error patterns with solutions
- **successes**: Successful patterns that worked well
- **feedback**: User preferences and corrections
- **platform**: Platform-specific adaptations (Windows/macOS/Linux)
