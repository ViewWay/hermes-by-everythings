# /hbe-plan

Create comprehensive implementation plans before writing code.

## Goal
Understand requirements, assess risks, and create step-by-step plan.

## Steps
1. Restate requirements clearly
2. Identify risks and blockers
3. Break down into phases
4. Estimate complexity
5. WAIT for user confirmation before proceeding

## Output
Structured plan with phases, dependencies, and risk assessment.
